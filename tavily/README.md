# LangGraph + Tavily Search Agent

A lightweight conversational graph agent built with **LangGraph** and **LangChain**. It uses OpenAI's models to handle conversation and intelligently routes to the **Tavily Search API** when it needs to look up real-time information on the web.

---

## 🛠️ Prerequisites

Before running the project, ensure you have:
* Python 3.10 or higher installed.
* [uv](https://github.com/astral-sh/uv) installed (recommended fast package manager).
* An OpenAI API key with an active billing balance.
* A Tavily API key for web search capabilities.
